Политика конфиденциальности

Последнее обновление: 18 августа 2026 года

1. Какие данные могут собираться

При заполнении формы пользователь может добровольно предоставить:

  • имя;
  • имя пользователя или контакт в Telegram;
  • адрес электронной почты;
  • номер телефона, если соответствующее поле будет добавлено в форму;
  • предпочтительный способ связи;
  • ответы на вопросы анкеты;
  • другую информацию, которую пользователь добровольно укажет в свободном текстовом поле.

Собираются только те данные, которые необходимы для обработки заявки и последующей связи с пользователем.

2. Цель обработки данных

Предоставленные данные используются для:

  • обработки заявки пользователя;
  • обратной связи;
  • общения через Telegram или электронную почту;
  • телефонного звонка, если пользователь добровольно укажет номер телефона;
  • понимания интересов и вопросов пользователя для подготовки ответа;
  • ведения истории обращений;
  • улучшения работы формы и взаимодействия с посетителями сайта.

Персональные данные не используются для целей, несовместимых с указанными выше, без получения отдельного согласия пользователя.

3. Согласие пользователя

Перед отправкой формы пользователь самостоятельно устанавливает отметку о согласии на обработку предоставленных данных.

Согласие является добровольным.

Если пользователь не согласен с обработкой данных, он может не отправлять форму.

Пользователь может отозвать ранее предоставленное согласие, обратившись по контактам, указанным в настоящей Политике.

4. Используемые сервисы

Для работы формы используется сервис Tally.

После отправки формы информация может:

  • сохраняться в системе Tally;
  • отображаться владельцу сайта в разделе заявок;
  • направляться владельцу сайта по электронной почте.

Сайт размещён с использованием инфраструктуры Netlify.

Для получения уведомлений и обработки электронной почты могут использоваться почтовые сервисы.

Эти сервисы могут обрабатывать технические и персональные данные в объёме, необходимом для предоставления своих услуг.

5. Передача данных третьим лицам

Персональные данные не продаются и не передаются третьим лицам для их самостоятельного рекламного или маркетингового использования.

Доступ к данным могут получать сервисы, технически необходимые для работы сайта и формы, включая Tally, Netlify и используемые почтовые сервисы.

Передача данных также может осуществляться в случаях, предусмотренных законодательством.

6. Срок хранения

Данные хранятся не дольше, чем это необходимо для обработки заявки, общения с пользователем и разумного ведения истории обращений.

Пользователь может обратиться с просьбой удалить предоставленные им данные.

7. Права пользователя

Пользователь имеет право:

  • узнать, какие его персональные данные обрабатываются;
  • получить информацию о цели их обработки;
  • уточнить или исправить свои данные;
  • обратиться с просьбой об их удалении;
  • отозвать ранее предоставленное согласие;
  • получить информацию о порядке обработки своих данных.

8. Безопасность данных

Принимаются разумные организационные и технические меры для защиты полученных данных от несанкционированного доступа, изменения, распространения или уничтожения.

При этом ни один способ передачи или хранения информации в интернете не обеспечивает абсолютной безопасности.

9. Контакт по вопросам персональных данных
